- **想扩展 Agent**：阅读 [CLI Adapter 接入指南](./cli-adapter.md)。
- **想新增故障或修改 Runner**：阅读 [开发者手册](./developer-guide.md)，再看 [技术说明](./technical.md)。
- **想了解边界和缺口**：看 [设计说明](./design.md) 与 [功能缺口](./roadmap.md)。
